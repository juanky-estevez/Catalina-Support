# Soporte de la comunidad

Catalina Support está en desarrollo previo a 1.0 y el soporte comunitario se presta con el tiempo
disponible, sin plazo garantizado.

- Usa **GitHub Discussions** para instalación, configuración y preguntas abiertas.
- Usa **GitHub Issues** para defectos reproducibles y propuestas concretas.
- Usa **Private Vulnerability Reporting** para vulnerabilidades y datos sensibles; consulta
  `SECURITY.md`.

Antes de preguntar, sigue el README, revisa las discusiones existentes y adjunta versiones, sistema
operativo, comando ejecutado y el fragmento mínimo de registro. Borra tokens, correos, dominios y
otros datos privados.
